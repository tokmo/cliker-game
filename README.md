# 🎮 Clicker Game

Un jeu de clicker addictif et coloré créé avec HTML, CSS et JavaScript vanilla.

## 🚀 Comment jouer

1. Ouvrez `index.html` dans votre navigateur
2. Cliquez sur le gros bouton pour gagner des points
3. Achetez des améliorations pour automatiser la production de points
4. Progressez et débloquez des générateurs de plus en plus puissants !

## ✨ Fonctionnalités

- **Système de clic** : Gagnez des points à chaque clic
- **Améliorations** : 10 types d'améliorations différentes
  - 👆 Curseur - +0.1 points/sec
  - 👵 Grand-mère - +1 point/sec
  - 🌾 Ferme - +8 points/sec
  - ⛏️ Mine - +47 points/sec
  - 🏭 Usine - +260 points/sec
  - 🏦 Banque - +1400 points/sec
  - ⛩️ Temple - +7800 points/sec
  - ✨ Double clic - x2 points par clic
  - 💫 Super clic - x5 points par clic
  - 🌟 Mega clic - x10 points par clic

- **Sauvegarde automatique** : Votre progression est sauvegardée automatiquement
- **Interface responsive** : Jouable sur ordinateur et mobile
- **Animations** : Effets visuels et nombres flottants

## 🎯 Objectif

Accumulez le plus de points possible en cliquant et en achetant des améliorations stratégiques !
